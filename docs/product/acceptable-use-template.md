# Acceptable Use Template

Students should use school-owned managed tablets only for approved learning activities.

Students should not attempt to:

- Install unapproved apps.
- Use VPNs or bypass tools.
- Open unapproved browsers or websites.
- Disable the launcher or device policy.
- Factory reset or tamper with the device.
- Share the device with unauthorized users.

Lost or damaged devices should be reported to the school support contact immediately.
