# Privacy Notice Template

The device management program controls school-owned learning devices so students can access approved learning apps and websites during school activities.

The platform may log:

- Device enrollment and inventory status.
- Policy and app deployment status.
- Remote support commands.
- Aggregated blocked web access events.
- Admin and support actions.

The platform must not provide:

- Covert webcam monitoring.
- Covert microphone access.
- Keylogging.
- Secret screenshots.
- Private message inspection.
- Always-on home surveillance.

Schools should have legal counsel review this template before use.
